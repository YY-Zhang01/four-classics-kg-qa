## 编写规则

1. 每个章节的内容**必须**来自下方参考资料，不得编造或推测
2. 每个章节标注 source_chunk_ids：列出本章节引用了哪些资料块（用资料编号，如 ["资料1", "资料3"]）
3. 如果某章节在资料中找不到对应内容，该章节 content 填 "资料不足"
4. 对整页给出 confidence 评分（0.0-1.0）：
   - 0.9+：资料充足，信息明确
   - 0.7-0.9：大部分信息有依据，少量需推断
   - 0.5-0.7：资料较少，多处依赖推断
   - 0.5 以下：资料严重不足

## 输出格式

严格按以下 JSON 格式输出，不要输出任何其他内容：

{{
  "title": "页面标题",
  "page_type": "{page_type}",
  "confidence": 0.85,
  "entities": ["相关实体1", "相关实体2"],
  "sections": {{
    "章节名1": {{
      "content": "章节内容（基于原文）",
      "source_chunk_ids": ["资料1", "资料3"]
    }},
    "章节名2": {{
      "content": "资料不足",
      "source_chunk_ids": []
    }}
  }}
}}
